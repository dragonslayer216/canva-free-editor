# Canva-style local editor

This project is a simple Canva-like editor that runs locally in your browser.

Features:
- Add text, rectangles, and circles
- Drag elements around the canvas
- Edit size, position, and color
- Save and load your layout in local storage
- Export the design as JSON

## Run it locally

Open `index.html` in a browser.

## Notes

This is a local editor for your own designs and is intentionally easy to modify. It is not a bypass of any platform permissions or access control.
